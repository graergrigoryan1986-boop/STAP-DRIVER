# STAP DRIVER — ՍԹԱՓ ՎԱՐՈՐԴ

Սթափ վարորդի ծառայության հարթակ՝ մեկնարկը Երևանում։

## Կայք և վիզուալ խմբագրիչ
- `index.html` — հանրային կայք։
- `editor.html` — քաշելով-տեղադրելով տեսողական խմբագրիչ։
- Խմբագրիչում հնարավոր է տեղափոխել բաժինները, ավելացնել/ջնջել/կրկնօրինակել տարրերը, փոխել տեքստերը, գույները, չափերն ու դասավորությունը։
- Սևագիրը պահպանվում է ձեր դիտարկչում։ «Ներբեռնել կայքը» կոճակը ստեղծում է նոր `index.html` ֆայլ։ Այն ուղարկեք ChatGPT-ին, և այն կտեղադրվի GitHub-ում։

## GitHub Pages
Մի անգամ բացեք Settings → Pages և Build and deployment բաժնում ընտրեք **GitHub Actions**։ Դրանից հետո կայքի թարմացումները կհրապարակվեն ավտոմատ։
- Կայք՝ https://graergrigoryan1986-boop.github.io/STAP-DRIVER/
- Խմբագրիչ՝ https://graergrigoryan1986-boop.github.io/STAP-DRIVER/editor.html

## Android APK
GitHub Actions-ում ընտրեք **Build STAP DRIVER APK** workflow-ը։ Հաջող ավարտից հետո ներբեռնեք `stap-driver-debug-apk` artifact-ը։

Սա նախնական MVP է։ Իրական պատվերների ընդունումը, հաճախորդների/վարորդների գրանցումը, ադմին վահանակը, քարտեզները և backend-ը դեռ պետք է միացվեն։
