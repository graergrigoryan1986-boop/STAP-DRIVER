# STAP DRIVER — Executive Mobility

Պրեմիում վարորդական ծառայության հարթակ՝ մեկնարկը Երևանում։

## Կայք և հավելված
- Հանրային կայք՝ https://graergrigoryan1986-boop.github.io/STAP-DRIVER/
- `index.html` և `app.js` — գործող frontend նախատիպ։
- `app/` — Android հավելվածի սկզբնական նախագիծ։
- `backend/` — Node.js + Express API, PostgreSQL/Prisma տվյալների մոդել, JWT մուտք, bcrypt գաղտնաբառերի hash, պատվերների API, վարորդների GPS հաղորդումներ, ադմինի հաշվեկշռի լիցքավորում և WebSocket իրադարձություններ։

## Backend-ի ներկա հնարավորությունները
- Հաճախորդի և վարորդի գրանցում։ Ադմինի գրանցում բաց չէ։
- JWT-ով պաշտպանված մուտք և դերերի ստուգում։
- PostgreSQL տվյալների բազայի սխեմա։
- Պատվերի ստեղծում, վարորդի կողմից ընդունում, ընթացքի նշում և ավարտ։
- Պատվերի գումարի 25% միջնորդավճար և վարորդին 75% հաշվարկ։
- Ադմինի կողմից վարորդի հաշվեկշռի ձեռքով լիցքավորում։
- Վարորդի GPS կոորդինատների ընդունում և Socket.IO հաղորդումներ։
- Ադմինի կողմից հաշիվների արգելափակման endpoint։

## Backend-ի գործարկում
Տեղային փորձարկման համար՝

1. Տեղադրել Node.js 22 և PostgreSQL։
2. `backend/.env.example`-ից ստեղծել `backend/.env` և լրացնել իրական արժեքները։
3. `cd backend && npm install`
4. `npx prisma db push`
5. `npm start`

Պարտադիր միջավայրային արժեքներ՝ `DATABASE_URL`, առնվազն 32 նիշանոց պատահական `JWT_SECRET`, `ADMIN_EMAIL`, առնվազն 14 նիշանոց `ADMIN_PASSWORD`, և թույլատրված frontend դոմենների `CORS_ORIGINS` ցուցակը։ Գաղտնի արժեքները երբեք մի տեղադրեք GitHub-ում։

## Արտադրական տեղակայում
Ավելացվել է `render.yaml` Blueprint՝ API սերվերի և PostgreSQL տվյալների բազայի համար։ Այն տեղակայելու համար պետք է սեփական Render հաշվում ընտրել New → Blueprint և միացնել այս GitHub repository-ն։ Render-ը կպահանջի լրացնել `ADMIN_EMAIL` և `ADMIN_PASSWORD` գաղտնի միջավայրային արժեքները։

## Կարևոր
Backend-ի կոդն ու տվյալների մոդելը ավելացված են, բայց ծառայությունը դեռ չի տեղակայվել արտաքին հոսթինգում, իսկ հանրային frontend-ը դեռ չի միացվել API-ին։ Հետևաբար կայքում գրանցումն ու պատվերները դեռ չեն աշխատում այս backend-ով։ Android հավելվածում նույնպես դեռ պետք է միացնել իրական մուտքը, պատվերները և ֆոնային GPS-ը։ Արտադրական գործարկումից առաջ անհրաժեշտ են վարորդների ստուգման/հաստատման հոսք, ինտեգրված frontend, քարտեզային արտադրական ծառայություն, թեստեր, պահուստավորում և վճարումների իրավական/տեխնիկական կարգավորում։
