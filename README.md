# STAP DRIVER — Executive Mobility

Պրեմիում վարորդական ծառայության հարթակ՝ մեկնարկը Երևանում։

## Կայք
- Հանրային կայք՝ https://graergrigoryan1986-boop.github.io/STAP-DRIVER/
- `index.html` — սև, սպիտակ և շամպայն-ոսկեգույն դիզայն, ծառայություններ և պատվերի ձև։
- `app.js` — գրանցման/մուտքի ցուցադրական հոսք, հաճախորդի/վարորդի/կազմակերպության պրոֆիլներ, պատվերի ցուցադրական պահպանում և երթուղու հաշվարկ։
- `editor.html` — նախկին տեսողական խմբագրիչ։

## Ներկայիս գործառույթները
- Երեք հաշվի տեսակ՝ հաճախորդ, վարորդ, կազմակերպություն։
- Անձնական էջ՝ պրոֆիլի տվյալներով, վարկանիշի դաշտով, պատվերների պատմությամբ և առանձին ցուցադրական հաշվեկշռով։
- Սթափ վարորդ՝ հաճախորդի մեքենայով, ընկերության ավտոպարկ և մեխանիկի կանչ։
- Շտապ պատվեր կամ նախնական ամրագրում։
- Հասցեների հիման վրա ավտոմոբիլային երթուղու փորձնական հաշվարկ՝ OpenStreetMap Nominatim + OSRM հանրային ծառայություններով։
- Սթափ վարորդի սակագին՝ 1 կմ = 1,000 դրամ։ Նվազագույն վճարը դեռ սահմանված չէ։
- Ընկերության ավտոպարկի և մեխանիկի ծառայությունների արժեքը հաստատվում է առանձին։

## Կարևոր սահմանափակում՝ այս փուլում
Սա աշխատող frontend նախատիպ է, ոչ թե դեռ արտադրական backend։ Հաշիվները, մուտքի տվյալները, պատվերները և հաշվեկշիռը պահվում են միայն տվյալ դիտարկչի localStorage-ում։ Դրանք չեն համաժամացվում այլ սարքերի հետ, անվտանգ իրական հաշիվ չեն, պատվերները չեն ուղարկվում վարորդներին, իսկ հաշվեկշիռը իրական գումար չէ։ Իրական գործարկումից առաջ անհրաժեշտ է միացնել սերվերային backend և տվյալների բազա, անվտանգ authentication, վարորդների հաստատում, պատվերների բաշխում, վճարային մատակարար և քարտեզային ծառայության արտադրական API/սահմանաչափեր։ Քարտի տվյալներ այս կայքը չի հավաքում։
