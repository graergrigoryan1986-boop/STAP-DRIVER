# STAP DRIVER — ՍԹԱՓ ՎԱՐՈՐԴ

Սթափ վարորդի ծառայության հարթակ՝ մեկնարկը Երևանում։

## Նախագծի մասերը
- index.html — հայերեն ներկայացուցչական կայք և նախնական հայտի ձև։
- app/ — Android հավելվածի առաջին կառուցվածքը։
- .github/workflows/android.yml — GitHub Actions-ով APK-ի ավտոմատ հավաքում։

## APK ստանալը
1. Բացեք GitHub-ի Actions բաժինը։
2. Ընտրեք Build STAP DRIVER APK workflow-ը։
3. Սեղմեք Run workflow։
4. Ավարտից հետո բացեք հաջողված run-ը և ներբեռնեք stap-driver-debug-apk artifact-ը։

Սա նախնական MVP է։ Իրական պատվերների ընդունումը, օգտատերերի գրանցումը, վարորդների հավելվածը, ադմին վահանակը, քարտեզները և backend-ը դեռ պետք է միացվեն։
