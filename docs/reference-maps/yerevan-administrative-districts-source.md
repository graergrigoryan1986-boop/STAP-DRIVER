# Երևանի վարչական շրջանների քարտեզ — հաշվարկի աղբյուր

- Աղբյուրի էջ՝ https://oksanaharutyunyan.wordpress.com/2019/10/15/%D5%A5%D6%80%D6%87%D5%A1%D5%B6%D5%AB-%D5%BE%D5%A1%D6%80%D5%B9%D5%A1%D5%AF%D5%A1%D5%B6-%D5%B7%D6%80%D5%BB%D5%A1%D5%B6%D5%B6%D5%A5%D6%80%D5%A8/
- Էջի վերնագիր՝ Երևանի վարչական շրջանները
- Հրապարակման ամսաթիվ՝ 2019-10-15
- Էջում նշված է Երևանի 12 վարչական շրջանների բաժանումը և տեղադրված է քարտեզի պատկեր (Image 116)։
- Վարչական շրջանների անունները՝ Աջափնյակ, Ավան, Արաբկիր, Դավթաշեն, Էրեբունի, Կենտրոն, Մալաթիա-Սեբաստիա, Նոր Նորք, Նորք-Մարաշ, Նուբարաշեն, Շենգավիթ, Քանաքեռ-Զեյթուն։

## Օգտագործման սահմանափակում
Այս հղումը պահվում է որպես քարտեզի սկզբնաղբյուր/տեղեկանք։ Գների հաշվարկի համար քարտեզի սահմանների ճշգրիտ երկրաչափությունը պետք է ներբեռնել կամ թվայնացնել առանձին GIS տվյալաշարի մեջ և ստուգել պաշտոնական սահմանների հետ։ Միայն էջի առկայությունը դեռ չի ապացուցում, որ քարտեզի պատկերն արդեն ինտեգրված է հավելվածի հաշվարկային կոդում։
